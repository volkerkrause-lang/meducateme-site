Publishing controls

Publishing is authenticated by GitHub, not by a secret token in this webpage. A lesson must first be explicitly approved: its PR must no longer be a GitHub draft and must carry the approved-for-publish label. The publishing action checks those conditions again before it can merge anything into main.

Publish one / publish all approved

The action also requires typing PUBLISH. Draft and merely reviewed lessons are rejected automatically. This Draft Library page itself is public at /drafts/; the unfinished lesson content remains on its draft branch until publication.
